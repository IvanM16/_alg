# 旅行推銷員問題 (TSP) 演算法解答集

本專案使用 Python 實作了五種經典演算法來求解 **旅行推銷員問題 (Traveling Salesperson Problem, TSP)**。

---

## 📌 演算法簡介與原理

### 1. 貪婪演算法 (Greedy Algorithm / Nearest Neighbor)
* **原理**：從起點城市開始，每次皆選擇距離當前城市最近且未被造訪過的城市，直至所有城市皆訪問完畢後返回原點。
* **特點**：計算速度極快 ($O(N^2)$)，但容易陷於區域極值，結果往往不是最佳解。

### 2. 改良法 (Improvement Method / 2-Opt Heuristic)
* **原理**：從一個初始巡迴解出發，檢查將路徑中的任意兩條邊取消並重新交叉連接（即反轉子路徑區間）是否能減少總距離。
* **特點**：能有效消除路徑中的自相交現象（Self-crossing），大幅優化隨機解。

### 3. 爬山演算法 (Hill Climbing Algorithm)
* **原理**：屬於區域搜尋（Local Search）。在當前解的鄰域（如兩點對調 `2-swap`）中探索，一旦找到第一個比當前解更優的鄰居即進行轉移（First-Choice）。
* **特點**：概念簡單且收斂快速，但無法跳脫局部最佳解 (Local Optima)。

### 4. 梯度下降法 (Steepest Discrete Gradient Descent)
* **原理**：在連續空間中，梯度代表最陡峭的上升/下降方向；在離散的 TSP 空間中，將「離散梯度」定義為每個鄰域動作（如 2-Opt 移動）產生的代價變化量 $\Delta \text{Cost}$。演算法會在每一步評估**整個鄰域內所有可能方向**，並沿著下降幅度最大（負梯度最陡）的方向移動。
* **特點**：屬於極速下降法 (Steepest Descent)，比普通爬山法更為穩定且精準，但計算量較大。

### 5. 模擬退火法 (Simulated Annealing)
* **原理**：源自物理退火過程。高溫時以較高機率接受較差的新解（Metropolis 準則：$P = \exp(-\Delta E / T)$），從而有能力跳出局部最佳解；隨著溫度衰減，逐漸轉為局部搜尋。
* **特點**：具有全域搜尋能力 (Global Optimization)，能有效尋找到高質量的近似最佳解。

## 🚀 執行環境與使用方式

### 軟體需求
* **Python 3.7+** (僅使用標準函式庫 `math`, `random`, `time`)

### 執行步驟

1. **複製或下載專案**：
   確保 `tsp_solvers.py` 位於您的工作目錄中。

2. **執行 Python 腳本**：
   ```bash
   python tsp_solvers.py
   ```

## 📊 輸出範例

執行後將產生 30 個隨機座標的城市，並分別以五種演算法求解與評比：

```text
=== 生成 30 個隨機城市測試資料 ===

=================================================================
演算法名稱                                | 總距離 (Distance) | 執行時間 (Sec)
=================================================================
1. 貪婪演算法 (Greedy / Nearest Neighbor)   | 512.34            | 0.0002    
2. 改良法 (2-Opt Improvement)             | 438.12            | 0.0035    
3. 爬山演算法 (Hill Climbing)              | 445.67            | 0.0021    
4. 梯度下降法 (Steepest Gradient Descent)  | 429.85            | 0.0089    
5. 模擬退火法 (Simulated Annealing)        | 425.10            | 0.0450    
=================================================================
```
