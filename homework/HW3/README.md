# 習題 5：系統性列舉真值表解決 SAT 問題

本專案實作一個簡單且直觀的 **SAT Solver (布爾可滿足性求解器)**，透過**暴力列舉法 (Brute-Force Enumeration)** 系統性地建立真值表，檢查目標邏輯運算式是否存在至少一組賦值使得結果為 `True`。

## 演算法原理

1. **變數提取**：解析輸入的邏輯運算式，獲取所有獨立的布爾變數集合 $V = \{v_1, v_2, \dots, v_n\}$。
2. **真值表空間搜尋**：針對 $n$ 個變數，其組合空間為卡氏積 $\{0, 1\}^n$（即 $2^n$ 種可能的真值指派）。
3. **逐行評估 (Evaluation)**：將每種變數組合代入運算式求值：
   * 若運算式計算結果為 `True`（1），則記錄該組解。
4. **結果輸出**：
   * **SATISFIABLE (SAT)**：找到至少一組解使運算式成立。
   * **UNSATISFIABLE (UNSAT)**：搜尋完所有 $2^n$ 種組合後，無任何解能使運算式成立。

## 時間與空間複雜度分析

| 項目 | 複雜度 | 說明 |
| :--- | :--- | :--- |
| **時間複雜度** | $\mathcal{O}(2^n \cdot M)$ | $n$ 為變數個數，$M$ 為計算單一邏輯運算式的時間。 |
| **空間複雜度** | $\mathcal{O}(n + M)$ | 主要消耗於儲存遞迴/迭代狀態與變數字典。 |

> **註**：SAT 為第一個被證明為 **NP-Complete** 的經典問題。暴力列舉法適用於變數數量較小的情況（如 $n \le 20$）；當 $n$ 較大時，將面臨組合爆發，實務上通常需要改用 **DPLL**、**CDCL** 等進階 SAT Solver 演算法。
